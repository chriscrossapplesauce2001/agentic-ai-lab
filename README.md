# Agentic AI Lab

Module infAgAI. Fourteen labs that build up an AI agent step by step: what an
agent is, the loop that drives it, the tools it calls, and what it takes to
make one reliable, observable and safe.

## The labs

Work through them in order. Each one builds on the last.

| | |
|---|---|
| **Lab 01** Foundations | What counts as an agent, and a first model call |
| **Lab 02** Agent Loop | The reason, act, observe cycle |
| **Lab 03** Tools and MCP | Giving the agent tools, and the protocol behind them |
| **Lab 04** Prompting | Getting the behaviour you asked for |
| **Lab 05** Reasoning Models | Models that think before they answer |
| **Lab 06** Orchestration | Several steps working as one pipeline |
| **Lab 07** Frameworks | What the frameworks do for you |
| **Lab 08** Memory | Carrying context across turns |
| **Lab 09** RAG | Answering from your own documents |
| **Lab 10** Sandboxing | Running generated code without trusting it |
| **Lab 11** Observability | Seeing what the agent actually did |
| **Lab 12** Multi Agent | Several agents working together |
| **Lab 13** Security | Prompt injection and what it breaks |
| **Lab 14** Evaluation | Deciding whether it is any good |

Each lab is a folder holding one notebook plus the data it needs. Open the
notebook, not the folder.

## How to work

1. Open a lab from the start page and run the cells from top to bottom.
2. Fill in every gap marked with `___` before running the cell below it.
3. Your work saves by itself. Sign in again later and it is still there.

## What runs where

The language models run on the lab server, not on your laptop. There is
nothing to install and no API key to enter. Everything happens in your browser.

Because everyone shares one server, a cell can take a few seconds longer when
the lab is busy. That is normal.

## If something goes wrong

| Problem | What to do |
|---|---|
| An error says a name is not defined | You have most likely left a `___` gap unfilled further up. This is the most common cause, and the message can look like a server problem when it is not |
| A cell hangs or the output looks stuck | Kernel menu, then "Restart Kernel", then run again from the top |
| A notebook will not open at all | Ask the lab instructor |
| You forgot your password | Ask the lab instructor, it can be reset |
